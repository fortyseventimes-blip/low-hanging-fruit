## ADDED Requirements

### Requirement: Извлечение оценки навыка из свободного текста
Система SHALL анализировать `User.resume_text` через Claude API и
создавать `UserSkillAssessment` с `evidence_source = resume_nlp` для
каждого навыка, для которого в тексте нашлось явное или косвенное
свидетельство.

#### Scenario: В резюме явно упомянут навык
- **WHEN** текст резюме содержит формулировку, однозначно соответствующую
  `Skill.key_question`
- **THEN** создаётся `UserSkillAssessment` с `inferred_rating` и
  `evidence_source = resume_nlp`

#### Scenario: Косвенное свидетельство сильной стороны
- **WHEN** в тексте нет прямого названия навыка, но описанные обязанности
  соответствуют модели/инструменту навыка (`Skill.models`)
- **THEN** создаётся `UserSkillAssessment` с `inferred_rating` не выше 3
  из 5 (косвенная оценка не может быть максимальной) и пометкой источника
  для последующего ручного подтверждения пользователем

### Requirement: Пользователь может подтвердить или отклонить выявленную оценку
Раскрытие скрытых сильных сторон — ключевая ценность продукта, поэтому
интерфейс SHALL показывать `inferred_rating` как предположение, а не факт,
до подтверждения пользователем.

#### Scenario: Пользователь подтверждает предположенный навык
- **WHEN** пользователь нажимает "Да, это так" на карточке с
  `evidence_source = resume_nlp`
- **THEN** создаётся или обновляется `UserSkillAssessment` с
  `self_rating`, равным подтверждённому значению

#### Scenario: Пользователь отклоняет предположение
- **WHEN** пользователь нажимает "Не совсем"
- **THEN** `inferred_rating` не участвует в дальнейшем расчёте разрыва с
  когортой для этого навыка
