## ADDED Requirements

### Requirement: Онбординг занимает не больше 7 минут
Система SHALL собрать резюме/свободный текст, гео и индустрию за один
сеанс не дольше 7 минут, без промежуточного сохранения на сервере до
завершения последнего шага.

#### Scenario: Пользователь проходит онбординг целиком
- **WHEN** пользователь вводит текст о себе, гео и индустрию и нажимает "Готово"
- **THEN** система создаёт запись `User` со всеми полями и переходит к
  экрану ассессмента без дополнительных обязательных шагов

#### Scenario: Пользователь прерывает онбординг
- **WHEN** пользователь закрывает вкладку до нажатия "Готово"
- **THEN** запись `User` не создаётся и данные не сохраняются

### Requirement: Гео и индустрия определяют набор структурных барьеров
Система SHALL использовать поля `geo` и `industry` пользователя, чтобы
включить только относящиеся к этой стране/индустрии записи
`StructuralBarrier` для целевых `RoleProfile`.

#### Scenario: Пользователь из Германии смотрит роль с барьером на диплом
- **WHEN** `User.geo == "Germany"` и целевая `RoleProfile` имеет
  `StructuralBarrier(barrier_type=education)`
- **THEN** интерфейс показывает этот барьер вместе с `exception_pct`
  (доля людей без диплома, всё равно занимающих роль)

#### Scenario: Тот же барьер не показывается для роли не в Германии
- **WHEN** `User.geo != "Germany"`
- **THEN** барьер, привязанный к `geo == "Germany"`, не отображается для
  этого пользователя
