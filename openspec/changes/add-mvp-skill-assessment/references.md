# Референсы

## Структурный референс карты навыков (первичный)
- **PAF Skill Map** — Сергей Тихомиров, productframework.ru/skill_map.
  Секторы × кольца зрелости × связи × ключевой вопрос на карточку.
  Лицензия CC BY-SA 4.0, атрибуция обязательна при адаптации.
  https://productframework.ru/skill_map

## Интерактивная визуализация графа навыков
- **roadmap.sh** (Kamran Ahmed, open-source, 2017–). Интерактивные
  node-based карты по ролям, React-рендерер поверх JSON/YAML-описания
  узлов, клик по узлу подсвечивает связи, не весь граф. Прямой референс
  для механики `ConnectionLine` и общей идеи "не статичная картинка, а
  кликабельный граф".
  https://roadmap.sh · исходники: github.com/kamranahmedse/developer-roadmap

## Геймификация и retention-механики
- **Duolingo** — стрики, XP, "safe failure" (мягкая обратная связь на
  ошибку). Важная методологическая находка: в 2022 Duolingo перешёл от
  свободного skill-дерева к линейному пути для новичков — completion rate
  вырос. Вывод для нас: линейный путь — для онбординга, дерево/карта — для
  результата после, не как форма ввода.
- **Strava** — сравнение с распределением ("ты быстрее 72% бегунов твоей
  возрастной группы"), не абсолютные лидерборды с именами для
  чувствительных метрик. Референс для `CohortMarker`.
- **Codewars / LeetCode** — kyu/rank-система, "одна следующая конкретная
  задача под твой уровень". Референс для `RecommendationCard`.

## Визуальная система "созвездия" (принято как основная эстетика, 2026-09-02)
Тёмный космический холст, кластеры-"созвездия" с glow-эффектом на цвет
домена, тонкие связи внутри и между кластерами, механика масштаба
(общий вид галактики → один кластер → один узел) для плотных карт
(в референсе — 570 узлов в 17 созвездиях). Прямое решение проблемы
визуального шума на 71+ узлах, которую давала плоская геометрия PAF.
Скриншоты предоставлены пользователем 2026-09-02, источник инструмента
не установлен.

## RPG-механика (визуальный язык, не движок)
- Character sheet / skill radar-chart паттерны из настольных и видео-игр
  — референс для будущей альтернативной визуализации профиля одним
  взглядом (вне скоупа MVP, но зафиксировано как возможное развитие
  `SkillNode`-агрегата).
- **Microsoft Flight Simulator 2024, карьерный режим** — состояния узла
  "закрашен + галочка" / "серый + замок", референс для состояний
  `SkillNode` (не для геометрии карты — геометрию берём от PAF).

## B2B skill-gap инструменты (рынок, не дизайн — для контекста
отстройки)
Pluralsight Skills, iMocha, Skills Base, Fuel50, TalentGuard — все
заточены под HR/корпоративный B2B use case, ни один не работает как
самостоятельный B2C-инструмент с игровой подачей и когортным
бенчмаркингом снаружи компании. Прямых B2C-конкурентов в этой нише на
момент ресёрча не найдено — это и есть точка дифференциации.
